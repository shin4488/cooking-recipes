# App Store に入れる内容

App Store Connect に入れる文面と、質問への回答の下書き。運営者名・連絡先などの個人の情報はここに書かず、App Store Connect に入力するときに入れる。

他社の商標をアプリ名・キーワード・スクリーンショットに使わないよう、対応サイトの名前は載せない（[審査ガイドライン 5.2.1](https://developer.apple.com/app-store/review/guidelines/#intellectual-property)・[2.3.7](https://developer.apple.com/app-store/review/guidelines/#accurate-metadata)）。

| 価格 | 無料 |
| 配信する国・地域 | 日本 |

## 説明文

プロモーションテキスト（170文字まで）:

```text
気になったレシピのURLを、タグを付けて端末に保存。あとからタイトル・タグ・サイト名で探して、すぐに元のページを開けます。会員登録は不要です。
```

説明（4,000文字まで）:

```text
レシピぽけっとは、ネットで見つけたレシピのURLを、タイトルとタグを付けて保存しておくアプリです。作りたいときに、タイトル・タグ・サイト名で探して、元のページをすぐに開けます。

■ 保存
・Safari などの共有ボタンから、そのまま保存できます
・URLを貼り付けて登録することもできます
・一部のレシピサイトでは、保存したあとにページのタイトルを自動で入れます

■ 整理と検索
・牛肉・朝ごはん・お弁当などのタグを付けて整理できます
・複数の語で絞り込めます。一覧のタグをタップすると、そのタグで絞り込みます
・並び順は自由に変えられます

■ データの扱い
・会員登録は不要です
・保存したレシピは、端末の中だけに保存します
・削除したレシピは、30日間ごみ箱から戻せます
・利用状況の送信は、設定でいつでも止められます
```

キーワード（100文字まで、カンマ区切り）:

```text
レシピ,保存,料理,献立,ブックマーク,タグ,整理,お気に入り,URL,メモ,自炊,時短,スクラップ,あとで見る
```

## App のプライバシー（回答案）

アプリが外部に送るのは、Google Analytics for Firebase の利用状況だけ（[プライバシー説明](../RecipePocket/Support/PolicyText.swift)）。Google の説明では、既定で集めるのはアプリインスタンス ID と操作の記録で、位置情報は IP アドレスから大まかに推定し、広告 ID とは結び付けない（[Google の説明](https://support.google.com/analytics/answer/10285841?hl=ja)）。

| 質問 | 回答案 |
| --- | --- |
| データを収集するか | はい |
| データの種類 | 使用状況データ（製品の操作）、識別子（デバイス ID）、位置情報（おおよその位置情報） |
| ユーザーに関連付けるか | いいえ（アプリでユーザー ID を設定していない） |
| トラッキングに使うか | いいえ（広告識別子を使わない `FirebaseAnalyticsCore` を使い、他社のデータと結び付けない） |
| 利用目的 | アナリティクス |

- アプリインスタンス ID を「デバイス ID」に当てはめるかなど、Apple の分類への当てはめは Google の説明に書かれていない。提出前に Apple の [App のプライバシーの説明](https://developer.apple.com/app-store/app-privacy-details/)で確かめる。
- Firebase Installations は、端末・OS・アプリの種類（ユーザーエージェント）を集めるが、利用者や端末の識別子と結び付けない（[Firebase の説明](https://firebase.google.com/docs/ios/app-store-data-collection)）。
- 問い合わせのメールは、利用者がメールアプリから送る。申告が要るかは、提出前に Apple の説明で確かめる。

## 年齢制限の質問に答えるための事実

| 内容 | このアプリ |
| --- | --- |
| 暴力・性的な表現・ギャンブルなど | ない |
| アプリの中で自由に Web を見る機能 | ない。レシピのページは Safari などの別のアプリで開く |
| 利用者が作った内容の公開・共有 | ない。保存した内容は本人の端末にだけあり、ほかの人には見えない |
| 広告 | 最初の版には入れない。入れるときは回答を見直す |
| 端末の位置情報サービス・連絡先などの利用 | ない |

## App Review へのメモ

```text
ログインは不要です。
Safari でレシピのページを開き、共有ボタンから「レシピぽけっと」を選ぶと、保存の画面が開きます。
設定の「タイトルを取得する対応サイト」にあるサイトの公開レシピだけ、保存したあとにタイトルを自動で取得します。
利用状況の送信は、設定の「プライバシーと外部送信」でオフにできます。
```
