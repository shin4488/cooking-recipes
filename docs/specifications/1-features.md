# 機能

気になったレシピのURLをタグで整理し、あとから探して元サイトを開く。会員登録・ログインは不要。日本向けの無料アプリとし、広告を表示する。登録件数や基本機能に課金制限は設けない。

## 登録・閲覧・編集

レシピ一覧を起点にする。独立した詳細画面は設けず、編集などの操作方法は実装時に決める。

| 操作 | 動作 |
| --- | --- |
| 登録 | URLを貼り付けるか、Safari・Chrome等の共有から追加。URL・タイトル・タグを同じ画面で確認して保存する。URLのみ必須 |
| 共有から登録 | 複数URLは1つ選ぶ。共有画面内で保存を完了し、通信待ち・本体の強制起動は不要。取消時は保存しない |
| 一覧を見る | URLへのリンク付きタイトルとタグを表示。タグが多い場合は「もっと見る」などで展開して全件を確認できる。表示件数・表記は実装時に決める |
| 元サイトを開く | リンク付きタイトルをタップ。既定ブラウザまたはOSの設定に応じた対応アプリで開く。戻ると検索条件・表示位置を保つ |
| 編集・その他の操作 | 一覧からタイトル・URL・タグの編集、URLコピー、削除を行える |
| 設定 | 対応サイト、ごみ箱、広告とプライバシーの説明・必要な同意設定、利用条件、問い合わせ |

- タイトルは共有元、または[対応サイト](2-data.md#サイト別のタイトル取得)から補完する。取得できない場合は手入力で補え、タイトルなしでも保存できる。過去の記録のタイトルは一括取得しない。
- 保存成功後に完了を表示し、失敗時は入力を残す。登録0件なら登録方法、検索結果0件なら条件解除を案内する。
- 登録・URL編集の保存時に、別の記録と同じURLなら保存せず、既存記録を案内する。ごみ箱にある場合は復元か取消を選ぶ。タイトルやタグが同じでも保存できる。
- 削除した記録はごみ箱から30日間戻せる。完全削除・全件消去は件数を示して確認する。

## タグと検索

| 操作 | 規則 |
| --- | --- |
| タグの追加・編集 | 候補を選ぶか、新しい名前を入力。変更は編集中のレシピだけに反映する。入力途中の文字も保存時に1タグとして確定し、空白・読点では分割しない |
| タグの候補 | アプリが用意するタグと保存済みのタグを、重複をまとめて表示。部分一致で探せる。ユーザーが追加したタグは未使用になると候補から消え、アプリが用意するタグは残る |
| 検索条件の入力・削除 | 検索ボックスは1つ、合計200文字・20条件まで。半角・全角の空白で語を「×付きのチップ」にする。日本語変換中は確定せず、最後の語はチップになる前も検索する。「×」で個別削除、「すべてクリア」で全チップと入力中の文字を消す |
| 検索の一致条件 | 各語がタイトル・タグ・ホスト名のいずれかに部分一致し、すべての語を満たす記録を表示。全角・半角、英字の大小文字、ひらがな・カタカナは区別せず、記号はそのまま照合。推測・同義語変換はしない。条件なしは全件、ごみ箱は対象外 |
| タグから検索 | 一覧のタグをタップすると、タグ名を1つのチップとして検索ボックスに追加。検索時の表記ルールで同じ条件があれば追加しない。通常のキーワードと同じ対象を検索する |
| 並べ替える | 既定の並び順は登録順。ユーザーが変更した順序を保存し、検索結果にも反映する |

## 広告

- 入力中・編集画面には広告を表示しない。
- 全画面広告・強制動画は使わない。
- 広告の失敗・同意拒否でも基本操作を続けられる。
- 不適切な広告を報告できる。
